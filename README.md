# Street Fighter II — Native Arcade Recompilation

**Street Fighter II Native Recomp** is a fan-developed native arcade recompilation project dedicated to bringing three legendary versions of Capcom's Street Fighter II to modern Windows, Linux, and Steam Deck systems.

Built around the original CPS-1 arcade hardware architecture, this project aims to preserve the authentic Street Fighter II experience while introducing modern compatibility, enhanced configuration options, and quality-of-life improvements.

## Supported Game Editions

### Street Fighter II: The World Warrior (1991)
The original arcade release that revolutionized competitive fighting games.

- Eight playable World Warriors.
- Original character movesets, gameplay mechanics, and balancing.
- Classic arcade presentation, music, and sound effects.

### Street Fighter II: Champion Edition (1992)
The enhanced arcade version featuring expanded character selection and gameplay improvements.

- Four playable boss characters.
- Mirror matches.
- Updated character balancing and gameplay adjustments.
- Original Champion Edition arcade presentation.

### Street Fighter II: Hyper Fighting (1992)
The faster-paced arcade revision introducing additional gameplay refinements.

- Increased gameplay speed.
- Additional character moves and balance adjustments.
- Faster, more aggressive combat.
- Original Hyper Fighting arcade presentation.

## Project Features and Goals

- **Three-in-One Arcade Collection:** Access all three Street Fighter II versions through one native frontend.
- **Edition Selection:** Switch between The World Warrior, Champion Edition, and Hyper Fighting.
- **Native Recompilation:** Translate original arcade game code for modern PC execution.
- **CPS-1 Hardware Support:** Preserve original graphics, sound, input behavior, and arcade timing.
- **Save States:** Save and restore gameplay sessions.
- **Modern Frontend:** Arcade-inspired menus with edition selection and configurable settings.
- **Controller Support:** Keyboard, gamepad, and arcade-stick configuration.
- **Display Options:** Original aspect ratio, integer scaling, fullscreen, and CRT-inspired visual filters.
- **Audio Support:** Preserve original CPS-1 arcade music and sound effects.
- **Cross-Platform Development:** Target Windows x64, Linux x86-64, and Steam Deck.

## ROM Requirements

Users must supply their own compatible arcade ROM sets for the supported editions:

- `sf2.zip` — Street Fighter II: The World Warrior
- `sf2ce.zip` — Street Fighter II: Champion Edition
- `sf2hf.zip` — Street Fighter II: Hyper Fighting

Compatibility depends on the ROM revisions supported by the implementation.

No copyrighted ROMs, BIOS files, or original game assets are distributed with this project.
